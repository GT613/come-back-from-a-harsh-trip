# 逆旅来归：天镜寻踪

一款根据《逆旅来归》沙漠古城意象制作的非剧情向考古寻宝小游戏。

## 运行

直接双击 `index.html` 即可游玩。发布到 GitHub Pages 时，把 `game` 文件夹内的全部内容上传到仓库根目录，然后在仓库设置中启用 Pages。

## 操作

- 从营地选择难度、勘探编号和永久装备，再依次选择领队与两名队员进入 5×5 沙海地图。
- 三名队员的专长会同时生效；移动、风沙和意外会消耗个人状态，扎营可以恢复全队。
- 从营地出发，只能进入已探索区域旁边的格子。
- 先用罗盘勘测，再对高价值区域进行发掘。
- 发掘时用鼠标或手指刷开浮沙；获得遗物后按闪现顺序辨识纹样。
- 集齐“文、器、星”三种印记后前往城心，或随时提前撤离保全记录。
- 开启城心后还需完成“器物复位、拓片校准、星轨归一”三层深层机关，机关失误会降低最终归档完整度。
- 特定遗物可以组成“阴阳合璧、错代纪年、天镜星图”套装并获得额外价值。
- 提前撤离时可以选择稳妥原路、天镜捷径或就地扎营继续探索。
- 每轮结算会获得经验与研究经费，可解锁天镜挑战、图鉴和永久装备。
- 键盘方向键可以移动，数字键 `1`、`2`、`3` 可以切换工具。

进度保存在浏览器本地。游戏使用两首循环配乐，并由浏览器实时合成操作音效。受浏览器自动播放规则影响，进入营地后如果按钮显示“音乐：点击开启”，点击一次该按钮即可播放。
